常见问题

HarnessJob 是什么？

HarnessJob 是一个 AI 驱动的职位匹配工具，帮助求职者分析自身技能与目标 JD 的匹配度，也非常适合 HR 快速筛选候选人。

如何使用？

粘贴职位描述（JD）→ 上传简历（JSON / TXT / PDF）→ 点击「Run Analysis」，即可获得技能、经验、学历三维评分和 AI 建议。

支持哪些 AI 模型？

支持 Anthropic Claude、OpenAI GPT-4o、DeepSeek deepseek-chat。不填 API Key 时自动使用本地算法，无需任何账号。

我的简历和 API Key 会上传到服务器吗？

不会。所有计算完全在浏览器本地完成，数据不经过任何中间服务器，100% 隐私安全。

简历支持什么格式？

支持 JSON（精度最高）、TXT、PDF 三种格式。推荐使用 JSON 格式以获得最准确的技能匹配结果。
